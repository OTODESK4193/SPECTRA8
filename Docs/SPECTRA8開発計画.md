# 【最終確定・第2版】SPECTRA8 最高峰ハイブリッド・ボコーダー開発計画・完全仕様書

ご指示いただいた詳細な要件、および同じワークスペース内の他プロジェクト（`Granular`）に準拠したモジュレーションマトリクス仕様を含め、**一切の妥協のない最高峰の仕様・開発計画書**として再構築いたしました。

本計画書は、スカラー（非SIMD）ベースでの確実かつ安定した信号処理を前提とし、Ableton Live上での完全な動作と無類の音響表現力を約束するものです。

## 1. GUIレイアウトおよび全パラメータ仕様

ユーザーインターフェースは、「VOCODER」「EXCITATION」「MOD MATRIX」「BANDS EQ」の4つのタブで構成され、すべてリアルタイムに動的連動します。

### ① 「VOCODER」タブ (分析・変調セクション)
* **ノブ (11基)**:
  1. `CHARACTER`: 声の「キャラクター（質感）」を制御（フォルマント共振の物理的強度の調整）。
  2. `BANDS`: 分析・合成のバンド数（8.0〜48.0）。※EQ画面へ動的に追従。
  3. `FMT SHIFT`: 声道を擬似的に伸縮させるフォルマント・シフト（-24.0〜+24.0半音）。
  4. `FMT STRETCH`: フォルマントピークの間隔・広がりを非線形に伸縮（0.5〜2.0倍）。
  5. `TRACKING`: 入力ピッチへの追従比率（0.0%〜100.0%）。
  6. `ATTACK` / `DECAY` / `SUSTAIN` / `RELEASE`: MIDI駆動時のADSRエンベロープ（0.001s〜5.0s, Sustain: 0.0〜1.0）。
  7. `MIX`: Dry/Wet比率（0.0%〜100.0%）。
  8. `OUT LEVEL`: 最終出力レベル（-60.0dB〜+12.0dB）。
* **選択コンボボックス (6種)**:
  1. `LPC / FILTERBANK` (vocoderMode)
  2. `VOICING MODE` (mode: Auto / MIDI)
  3. `LIMITER` (limiterEnable: Off / On)
  4. `ANALYSIS WINDOW` (windowType: Hann / Hamming / Blackman)
  5. `LPC INTERPOLATION` (interpolationMode: LSP / LAR)
  6. `FILTERBANK TYPE` (filterbankType: BPF Bank / Subtractive LR4)
* **フリーズ制御**:
  - `Formant Freeze` ボタン: 音声のLSP/LARパラメータを瞬時にロック。

### ② 「EXCITATION」タブ (キャリア・音源セクション)
* **ノブ (5基)**:
  1. `WT POS`: ウェーブテーブルのモーフィング位置（0.0〜1.0）。
  2. `PULSE WIDTH`: パルス波形のデューティ比（5.0%〜95.0%）。
  3. `DETUNE`: ユニゾンピッチデチューン（0.0〜1200.0セント ※内部的に最大120セントにスケーリング）。
  4. `NOISE MIX`: 励起音へのノイズ（息成分）ブレンド量（0.0%〜100.0%）。
  5. **`LOFI` (独立実装)**: ビット数低減（1bit〜24bit）、サンプルレート低減（100Hz〜44.1kHz）、ピッチの段階的量子化を制御。
* **選択コンボボックス (1種)**:
  1. `EXCITATION WAVEFORM` (waveform: Sawtooth / Pulse / Wavetable)。
* **Wavetable 読み込みインターフェース**:
  - **ドラッグ＆ドロップ (D&D) エリア**: UI上にオーディオファイル（`.wav` 等）を直接ドロップ可能。
  - **フォルダ追加＆ブラウザ**: 登録フォルダからクリック選択できるカスタムWavetableブラウザ。

### ③ 「MOD MATRIX」タブ (モジュレーションマトリクス) ※Granular準拠
* **仕様**: LFOやENVをソースとして、主要なボコーダーパラメータをモジュレートする16スロットの変調マトリクス。
* **モジュレーションソース (16種類)**:
  - `None` (無効)
  - `LFO 1〜4` (Sine/Triangle/Saw/Square/S&H/Chaosの6波形、テンポ同期対応)
  - `ENV 1〜3` (ループ可能なADSRエステートマシン)
  - `Velocity`, `Note`, `Mod Wheel`, `Random` (ノート毎のS&H)
  - `Macro 1〜4`
* **変調デスティネーション (SPECTRA8固有)**:
  - `formantShift`, `formantStretch`, `character`
  - `wavetablePosition`, `pulseWidth`, `detune`, `noise`
  - `lofi`, `mix`, `outputLevel`
* **マトリクスエディタ (16スロット)**:
  - 各スロットで `Source × Amount (-1.0〜+1.0) × Uni/Bipolar極性変換` を指定。

### ④ 「BANDS EQ」タブ (動的ビジュアライザー・EQ)
* **動的バンド追従**:
  - `BANDS` パラメータ（8〜48）の変更に連動し、EQ操作点、および垂直レベルメーターの数が **8個〜48個の間で動的に増減・描画**されます。

## 3. 搭載技術・数理アルゴリズムの仕様

### ① 信号分析・信号処理パイプライン
* **固定内部サンプリングレート処理 (16kHz)**:
  - フォルマント解像度向上のため、内部で 16kHz に再サンプリングして分析。
* **FIFO・オーバーラップ加算 (OLA)**:
  - フレーム長 $N=1024$、ホップサイズ $H=256$。ホストDAWに $N-H = 768$ サンプルの遅延（ルックアヘッド）を正確に報告（PDC）。
* **窓関数**:
  - ハン窓、ハミング窓、およびBlackman窓の動的選択。

### ② LPC (線形予測符号化) 技術
* **自己相関法 & Levinson-Durbin再帰**:
  - 16次の予測係数 $a_i$ および反射係数 $k_i$ を導出。反射係数を絶対安定領域 $|k_i| \le 0.98$ に制限。
  - **極性反転バグの完全解消**: 前回の `-a[i]` 反転を削除し、正当な符号 $a[i]$ のまま LSP 変換および逆変換へ引き渡し、フィルタの発振・NaN化を完全防止。
  - **帯域拡張 (Bandwidth Expansion)**: 予測多項式極の安定化のため、拡張係数 $\gamma = 0.96 \sim 0.985$ を適用。
* **LSP / LAR 変換とサンプル精度補間**:
  - **LSP最小ギャップ補正**: 隣接するLSP値の間に最小クリアランス $d_{min} = 0.05 \pi / \text{order}$ を強制確保。
  - LSPからLPCへの逆変換を毎サンプル実行し、時変IIRフィルタとして滑らかに駆動。

### ③ ピッチ検出 & V/UV判定
* **McLeod Pitch Method (MPM) & 放物線補間**:
  - 正規化自乗差関数（NSDF）を用いたピッチトラッキング。
* **多角的一致判定決定木**:
  - ZCR, Clarity, LBER, $G_{lpc}$ (予測ゲイン) を統合した有声判定。シュミットトリガー遷移によるチャタリングノイズ防止。

### ④ キャリア・再合成エンジン
* **PolyBLEPによるアンチエイリアシング**:
  - 矩形波および鋸歯状波の不連続点に対してPolyBLEP補正を行い、折り返し歪みを完全排除。
* **Wavetableモーフィング**:
  - `Wavetable Position` が 0.0〜1.0 に向かうに従い、以下の波形に滑らかにモーフィングします。
  - `Sine（正弦波）` → `Triangle（三角波）` → `Square（矩形波）` → `Sawtooth（鋸歯状波）` → `FM Synth Wave（FM合成金属波形）`
  - 読み込んだカスタムWavetableは自動で 2048 サンプルの単周期ウェーブテーブルへ再サンプリングされ、安全にフェードイン・アウト処理されます。
* **インテリジェント・シビランス・パススルー**:
  - サ行などの高域無声子音を検知した際、ボコーディングを通さずに生の入力子音成分をダイレクト出力にブレンド（Sibilance Bleed）し、抜群の歌詞明瞭度を実現。
* **ピッチ・ポルタメント**:
  - MIDI駆動時、ノート間を滑らかに滑空するポルタメント（0.0s〜2.0s）を実装。
* **ゲインマッチングとエンベロープフォロワー**:
  - 入力信号と合成信号のRMS比を算出し、アタック（約5ms）とリリース（約30ms）で平滑化されたエンベロープで合成音の音量を追従。

### ⑤ ステレオ音像解析と定位再現
* **定位と幅の動的解析**:
  - 左右エネルギー比（パン定位 $P_{pan}$）および相互相関係数（ステレオ幅 $C_{LR}$）を抽出。
* **ステレオ非相関化 (デコレレーター) 回路**:
  - オールパスフィルター（Allpass Filter）ネットワークおよびMSマトリクスを用い、モノラル再合成音からオリジナルのステレオ定位を完全復元。

## 4. Ableton Live 最適化・低遅延スカラー信号処理設計

1. **オーディオスレッドの完全なクラッシュフリーセーフガード**:
   - `prepareToPlay` がバックグラウンドで動的に再起動された際、FIFOおよび再サンプリング用のすべての配列へのアクセスを、厳密なサイズ・バリデーションで毎サンプル保護し、クラッシュ（アクセス違反）を完全に防止。
2. **C++スカラー設計への移行**:
   - 可読性とデバッグ性を追求し、難解なAVX2ベクトル命令を廃止。NaNが発生した場合には即座にそのサンプルを `0.0f` に安全クランプする「フェイルセーフ・ガード」を搭載。
