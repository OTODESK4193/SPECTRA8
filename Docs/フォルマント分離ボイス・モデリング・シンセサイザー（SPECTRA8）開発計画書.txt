フォルマント分離ボイス・モデリング・シンセサイザー開発計画書
OTODESK、これまでの壁打ちでブレインストーミングした全ての仕様を統合し、モジュレーション機構を追加した**「一切の漏れがない完全な開発計画書」**を策定しました。
AVX2（8レーン並列）のポテンシャルを極限まで引き出し、192kHz環境下でも圧倒的な音質と安定性を両立する、マスターピースにふさわしい設計図です。
1. 製品コンセプト ＆ 基本仕様
プラグイン種別: DAW用マルチエフェクト / シンセサイザー（VST3 / AU対応、JUCEフレームワークを使用）
コア技術: ハイブリッド分離（LPC × ケプストラム × フィルタバンク） ＆ 8音ポリフォニックWavetable再合成
対応環境:
サンプリングレート: 44.1kHz 〜 192kHz 完全対応
最適化仕様: AVX2（256bit SIMD）ネイティブ最適化、32バイトアライメント（alignas(32)）
チャンネル仕様: Mono Input ──> Stereo Excitation（パターン②）
2. システム・アーキテクチャ（全4セクション）
【第1セクション】ハイブリッド分析段（Analysis Stage）
入力された音声信号から「声道特性（フィルター包絡）」と「音源特性（ピッチ）」を高度に分離します。
マルチレート・ダウンサンプリング:
192kHz等の高SR入力を、分析パスのみ 16kHz（または22.05kHz）にダウンサンプリング して処理（負荷軽減と低域フォルマントの解像度向上）。
動的ウィンドウスケーリング:
サンプリングレートに応じてFFTサイズを動的に変更し、常に 20ms〜30ms相当の時間窓（44.1kHz時は1024サンプル、192kHz時は4096サンプル）を維持。
トリプル・ハイブリッド分析:
LPC（線形予測分析）: Levinson-Durbin再帰法により、シャープなフォルマントピーク（共振点）を正確に抽出（12〜18次、UIから次数変更可能）。
ケプストラム分析: ホモモルフィック処理（リフタリング）により、LPCが苦手な「零点（アンチフォルマント）」や全体のスペクトル傾斜、子音成分を滑らかに抽出。
フィルタバンク分析: メル尺度/Bark尺度に基づき、抽出した包絡データをUIのマッピングやモーフィング用の周波数バンドに割当。
【第2セクション】独自ボイスマネージャー ＆ 生成段（Generator Stage）
JUCEの標準クラスに依存せず、AVX2の並列化に特化した SoA（Structure of Arrays）構造 のシンセサイズエンジンをゼロから構築します。
ボイスアサイン仕様:
8音完全ポリフォニック。9音目受信時は「発音時刻が最も古いボイス」を上書きする 古い順スチーリング を採用。
ゲートオフ（無音化）したボイスはSIMDループから即座に除外（動的休止）。
1ボイス内ステレオ構造:
1つのAVXレーン（1ボイス）が、独立したLch/Rchの位相情報を持つ。
スーパーソウ・アプローチ（初期位相ランダム化）:
Note Onの瞬間、リアルタイム安全な高速乱数（Xorshift / LUT）を用いて、L/Rの初期位相（phaseL, phaseR）を完全にランダムにバラす。
UIの「Width/Detune」に基づき、Lchは低く（f_0 - \Delta f）、Rchは高く（f_0 + \Delta f）なるよう、独立した位相増分（phaseIncrementL/R）を設定。
励振信号ソース: 矩形波、ノコギリ波、およびカスタムWavetable（外部Wavファイル読み込み対応）。
【第3セクション】コントロール・レート ＆ LSP補間段（Interpolation Stage）
分析段（低SR・フレーム処理）から生成段（高SR・サンプル処理）への橋渡しを、絶対的なフィルター安定性とともに実現します。
LSP（線形スペクトル対）変換:
16kHz側で抽出されたLPC係数をLSP係数に変換。これにより、急激な変調でもフィルターが絶対に発振しない安定性を確保。
コントロール・レート設計:
生成段（192kHz）において、毎サンプルではなく 32〜64サンプルのブロック毎にLSPを直線補間 し、ブロック頭でLPC係数へ逆変換（大幅な負荷軽減）。
フォルマント・ハッキング:
補間前のLSP配列を直接シフト・ストレッチすることで、破綻のないリアルタイムな フォルマント・シフト、フォルマント・ストレッチ / スクィーズ を実現。
【第4セクション】モジュレーション・マトリクス（Modulation Stage）
Wavetableのインデックス移動やフォルマント変調を、音楽的かつ有機的にコントロールする機構。
モジュレーション・ソース:
ADSR（エンベロープ・ジェネレーター）: 各ボイスごとに独立。アタック、ディケイ、サスティン、リリースの時間軸変調。
LFO（低周波発振器）: ホストDAWテンポ同期対応。各種波形（サイン、三角、ノコギリ、矩形、ランダム（S&H））。
トリガーランダム（Per-Voice Random）: Note Onがトリガーされる度に、ボイスごとに異なる固定ランダム値を生成。
主要なターゲットパラメータ:
Wavetable インデックス（波形のスキャン位置）
フォルマント・シフト量
フォルマント・ストレッチ量
オシレーター・デチューン幅（Width）
3. 動作モードの仕様
4. AVX2（SIMD）実装設計仕様
LPCフィルターの差分方程式をボイス方向に並列化するため、以下のSoAメモリレイアウトを厳密に適用します。
y[n] = x[n] - \sum_{i=1}^{M} a_i y[n-i]
メモリアライメント: オシレーターのフェーズ、LPCの遅延バッファ（filterHistoryL[24][8], filterHistoryR[24][8]）を含むすべてのボイスデータ構造は alignas(32) で確保し、_mm256_load_ps による高速ロードを保証。
Vertical Vectorization: AVX2レジスタ（__m256）の8スロットに、ボイス0〜7の同一サンプルステップのデータを配置し、1命令で8ボイス分のL/RフィルターおよびWavetableのギャザーロード（_mm256_i32gather_ps）を一括演算。
5. 開発ロードマップ（全5フェーズ）
フェーズ1：分析エンジン ＆ プロトタイプ構築
[ ] Python（NumPy/SciPy）またはJUCEのオフライン処理にて、16kHzダウンサンプリング、LPC、ケプストラム抽出のアルゴリズム精度検証。
[ ] LPC \leftrightarrow LSP 変換、およびLSP上でのフォルマントシフト/ストレッチの挙動の数学的検証。
フェーズ2：SoA構造による独自シンセエンジンの実装（C++）
[ ] alignas(32) を用いたSIMDフレンドリーな独自ボイスマネージャーの構築。
[ ] 古い順スチーリング、およびNote On時のL/R独立ランダム位相（Xorshift/LUT）の実装。
[ ] 基本オシレーター（矩形波・ノコギリ波）とWavetable読み込み＆線形補間エンジンの構築。
フェーズ3：AVX2によるコアDSPの実装 ＆ コントロール・レートの統合
[ ] 8ボイス並列（Vertical Vectorization）によるL/R独立LPC再合成フィルターのAVX2アセンブリ/Intrinsics実装。
[ ] コントロール・レート（32〜64サンプル毎）のLSP直線補間 ＆ LPC逆変換機構の実装。
[ ] ケフレンシーピーク抽出によるピッチトラッキング（モードA）の実装。
フェーズ4：モジュレーション・マトリクス ＆ UIの実装
[ ] ボイス独立EG（ADSR）、LFO、トリガーランダムの実装と、SoAパラメータへのバインディング。
[ ] JUCEを用いた、グラフィカルなフォルマント包絡エディタ、Wavetableビジュアライザ、モジュレーション結線UIの作成。
フェーズ5：最適化・デバッグ ＆ 負荷テスト
[ ] 192kHz、8音ポリフォニック駆動時におけるホストDAW（インサイドオーディオスレッド）でのCPU負荷・スパイク計測。
[ ] デバッグアサーションを用いた、LSP補間時のフィルター安定性（単位円内への極の収束）の最終確認。
