## 留意点（計画書に明記がなく判断した箇所）

1. `vocoderMode=LPC` 選択時もフェーズ1では Filterbank で発音（HUDに "LPC (Phase2)" 表示）
2. `ANALYSIS WINDOW` / `LPC INTERPOLATION` コンボはフェーズ2で機能する（UIのみ先行）
3. ポルタメントのUI位置が計画書に未記載のため EXCITATION タブに PORTA ノブとして配置
4. DETUNE は計画書通り UI 0〜1200セント → 内部実効 0〜120セント
5. TRACKING デフォルトは 0%（MIDIモードでノートが入力ピッチに引っ張られないため）
6. BANDS EQ のゲインは -24〜+12dB、プラグインステートに保存される
