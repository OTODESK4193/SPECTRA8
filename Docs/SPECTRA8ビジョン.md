# SPECTRA8 製品ビジョン（2026-07-12 OTODESK指示）

## 目標

**Zynaptiq ORANGE VOCODER を超える**ことが目標。さらに **Sonic Charge BITSPEEK**
的な機能（LPC10風レトロ・スピーチコーデックの質感）も取り込み、
**エンジン（モデル）切り替え方式で使える最強のVocoder** を目指す。

## サウンドの理想像

- 喋り声が **サイバーパンク／近未来ボイス、ロボットボイス、デスボイス** 等に変幻自在
- **歌声** も主要ターゲット
- 声以外（**Bass、ドラム** 等）へのクリエイティブな使い方も想定
  → キャリア/モジュレーターの柔軟性、極端な設定でも破綻しない安定性が必須

## エンジン構想（vocoderMode をモデル切り替えに発展させる）

| モデル | 内容 | 状態 |
|---|---|---|
| Filterbank | アナログ風バンドボコーダー（BPF / LR4） | フェーズ1実装済 |
| LPC | 高精度フォルマント合成（LSP/LAR補間） | フェーズ2 |
| BitSpeek系 | LPC10風レトロコーデック（低次LPC+粗い量子化+ピッチ量子化） | フェーズ2〜3で検討 |

※ LOFIノブとの役割分担: LOFIは全モデル共通のポストエフェクト、
   BitSpeek系はフレームレート/次数/量子化を含むモデルそのもの。

## GUI方針

- お洒落さと**使いやすさ第一**を両立
- **機能ごとの色分け**（現状: VOCODER=ラベンダー / EXCITATION=ピンク /
  MOD=ライラック / BANDS EQ=ミント / ENV=ピーチ）を維持・徹底
- Granular準拠の操作系（右クリック数値入力、変調リング表示、GlowToggle）

## 競合機能チェックリスト（超えるべき点）

- ORANGE VOCODER: 高品位フィルターバンク、豊富なキャリア、フォルマントシフト、リバーブ等FX
- BITSPEEK: LPC10コーデック風、ピッチ量子化、ホールド/フリーズ、ロボティックな明瞭さ
- SPECTRA8の差別化: 16スロットModMatrix、48バンド動的EQ、モーフィングWT、
  V/UV自動ノイズ、シビランスパススルー、モデル切り替え
