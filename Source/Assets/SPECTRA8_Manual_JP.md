# SPECTRA 8 — 簡易マニュアル (日本語)

2つのエンジンを切り替えて使えるハイブリッド・ボコーダーです。クラシックな**フィルターバンク**方式と、声道モデルを使う**LPC**方式を搭載しています。

---

## 1. まず音を出す

1. **声**（モジュレーター）が流れているトラックに SPECTRA 8 を挿します。
2. キャリア（声を乗せる土台の音）の出し方を選びます。
   * **Auto モード** — プラグインが自分でキャリアを作り、声のピッチに追従します。
   * **MIDI モード** — MIDIキーボードでキャリアの音程を演奏します。
3. **MIX** を上げます。0% では原音がそのまま出ます（ボコーダーも**FXも完全にバイパス**されます）。100% で全処理音になります。

> **音が出ないとき:** Autoモードでは入力が検出できないと自動でゲートが閉じます。トラックに実際に音が来ているか、MIX が 0% になっていないかを確認してください。

---

## 2. 5つのタブとUIリサイズ

| タブ | 役割 |
|---|---|
| **VOCODER** | エンジンの選択と、声に関する主要コントロール |
| **EXCITATION** | キャリア（声を乗せる土台の音）の設定 |
| **MOD MATRIX** | LFO / エンベロープを任意のノブへ配線（全56宛先） |
| **FX** | 並べ替え可能な5スロットのエフェクト（COLORS移植） |
| **BANDS EQ** | ドラッグで操作する帯域EQ＋アナライザー |

> **画面サイズの変更:** プラグインウィンドウの右下または四隅をドラッグすることで、画面を自由に拡大・縮小できます（アスペクト比固定、25%〜200%）。サイズはDAWプロジェクトを閉じても自動的に記憶されます。

---

## 3. VOCODER タブ

### エンジンの選び方

* **Filterbank** — 声を8〜48バンドに分け、その音量をキャリアに転写します。輪郭がはっきりした、いわゆる王道のボコーダー音。
* **LPC Mode** — 声道をフィルターとしてモデル化し再合成します。フォルマントが自然で、LPC専用パラメータを使えば8bitロボット声まで作れます。

切り替えは30msの等パワークロスフェードで行われるので、音を出したまま操作しても問題ありません。

### 主要ノブ

| ノブ | 使いどころ |
|---|---|
| **CHARACTER** | 明瞭度。上げるほど子音がはっきりします |
| **TRACKING** | 0%＝BASE PITCH固定。100%＝声のピッチに追従 |
| **PITCH Q** | ケロケロ（オートチューン）の量。左のコンボで Key と Scale を指定します |
| **FMT SHIFT** | ピッチを変えずにフォルマントだけ移動。マイナスで太く、プラスで細く |
| **FMT STRETCH** | フォルマントの間隔を伸縮。SHIFTより穏やかで、性別モーフに便利 |
| **NOISE MIX** | 双方向。マイナスで息・子音のノイズを除去、0で声に応じて自動、プラスで強制的にノイズ |
| **M.PITCH** | キャリア全体を±24半音移調します。**スケール吸着より前**に掛かります |
| **MIX** | 原音 ⇔ 処理音。0%は完全バイパス |

### LPC専用パラメータ

| 項目 | 効果 |
|---|---|
| **ORDER** | 声道モデルの細かさ。16＝自然、8＝粗く、明らかに音量も上がります |
| **FRAME RATE** | 声道を解析し直す頻度。50Hz＝滑らか、8Hz＝カクついたトイ感 |
| **K QUANT** | 声道モデル自体をビットクラッシュ。3bitで完全にBitSpeek領域 |
| **INTERP** | フレーム間の繋ぎ方。Step＝急峻（レトロ）、LSP/LAR＝滑らか |
| **FREEZE** | 現在の母音の形をそのまま保持します |

## 4. EXCITATION タブ

キャリア＝声を転写する土台の音です。倍音が豊かで明るいキャリアほど、ボコーダーの言葉が聞き取りやすくなります。

* **波形** — Sawtooth（最も倍音が多く基本これでOK）、Pulse（細め・幅可変）、Wavetable。
* **カスタムWavetable** — 最初に **ADD DIR** でフォルダを登録します。**BROWSE** を押すと左にサブフォルダ、右に波形が並び、クリックで即座に読み込まれます。**RANDOM** はランダムに1つ選びます。登録フォルダは**DAWを再起動しても保持**されます。
* **DETUNE** — ユニゾンの広がり。セント値と度数を併記します（例 `700 ct (P5)`）。**SNAP** をONにするとドラッグが半音単位になります。
* **Morph** — 3種類を同時に掛けられます。
  * **BEND / BEND SYM** — 波形の位相を曲げます。奇数倍音が増えます。
  * **SYNC / SYNC PH** — ハードシンク風の繰り返し。攻撃的で金属的。
  * **VOCODE / VOWEL** — キャリアにA-I-U-E-Oのフォルマントを付けます。
  * Amount系ノブを0にするとその段は完全にバイパスされます。波形表示には3つすべてが反映されます。
* **LOFI** — ビット削減＋ピッチ追従のサンプル&ホールド。音程を下げずに粗くできます。

---

## 5. MOD MATRIX タブ

LFO 3基とループ可能なエンベロープ2基を、6スロットで配線します。

1. **Source** を選ぶ（LFO 1〜3 / ENV 1〜2 / Velocity / Note / Mod Wheel / Random）
2. **Destination** を選ぶ（VOCODER・EXCITATION・**FXタブの全ノブ（全56箇所）** が対象）
3. **AMT**（双方向）を設定。片側だけ振りたいときは **UNI** をON

変調が掛かったノブには、届く範囲を示す**ピンクの帯**と、現在値を示す明るいドットが**常時リアルタイムで表示**されます（無音時・自走LFOでも動きを目視確認できます）。LFOはフリーラン／テンポ同期（13種の音符）を選べます。

> **おすすめ:**
> - LFO 1（Saw）→ **Master Pitch**、AMT 0.5前後。PITCH Q を100%にして Key/Scale を決めておくと、曲に合わせて音階を駆け上がります。
> - LFO 2（S&H）→ **Resonator Shift**、AMT 0.5。レゾネーターの共振音程がステップ状に跳躍します。
> - ENV 1 → **Gate Decay**、AMT 0.7。ベロシティや打鍵に応じてゲートの余韻が伸縮します。

## 6. FX タブ

5スロットの直列接続です（COLORSより完全移植）。**カードをドラッグ**すると処理順を入れ替えられます。**クリック**すると下に詳細が出ます。

### Spectral Resonator

入力に反応して鳴る、8本のチューンド共鳴体です。完全なMIDIトラッキングに対応しています。

* **SCALE FOLLOW** — **Key / Scale 自動追従ボタン**。点灯時に有効。入力されたMIDIノートをVOCODERタブで選択されている現在の Key と Scale（20種類）の構成音へ瞬時にスナップ（最近傍音へ吸着）します。スケール外のキーを押鍵しても不協和音にならず、常に楽曲の調性に調和した美しい共鳴が得られます。
* **SHIFT** — **共鳴音程の半音移調（0〜+24st）**。MOD MATRIXから変調することでステップ状アルペジオやピッチベンドが可能です
* **DECAY** — **余韻の長さ（0.5ms〜3.0s）**。ピッチ補正済みなので、低い音でも高い音でも同じ長さで減衰します
* **DAMP** — 減衰しながら高域を落とします。上げるほど暗く落ち着いた余韻に
* **SHIMMER** — 1オクターブ上・2オクターブ上の**きらめきを上に足します**。Schroederオールパス拡散フィードバックにより浮遊感のあるリバーブのような尾を付加します
* **INHARM** — 実際の鐘のように上の部分音だけをずらします。うなりと金属感が加わります
* **SPREAD** — 8本の共鳴体のステレオ左右拡散（0〜100%）
* **OUT GAIN** — レゾネーターの出力ゲイン補正（-24〜+12dB）

### Multiband Drive

300Hz と 2.5kHz で3分割し、帯域ごとに別々に歪ませます。低域を保ったまま中域だけ汚せます。シェイプは **Tanh**（滑らか）/ **Fold**（激しい）/ **Crush**（デジタル）。

### Formant Gate

16ステップのテンポ同期スライサー（COLORS移植）。ステップごとに母音も切り替わります。

* **RATE** — 1ステップの長さ。1/2 〜 1/32
* **PATTERN** — **全50種類のリズムパターン**（王道トランス、3連符、付点ポリリズム、高速スタッター、スイング、変則チョップ等）
* **DECAY** — **ゲートの余韻（5ms〜1000ms）**。短くすると鋭角なプラック・チョップに、長くすると滑らかな呼吸感になります
* **VOWEL** — ステップ毎フォルマントの効き具合
* **SMOOTH** — ゲートの角を丸めます

### Ensemble Chorus / Reverb

幅出し・空間系です。リバーブには **PRE-DLY** / **WIDTH** / **LOW CUT**（余韻で低域が濁るのを防ぐ）/ **MOD**（金属的な鳴りを散らす）があります。

## 7. BANDS EQ タブ

* **グラフ上を直接ドラッグ**して帯域ごとに補正します
* バンドを**ダブルクリック**で0dBにリセット。**右クリック**で全リセットの確認バーが出ます
* EQカーブの背景にある色付きの曲線が**アナライザー**で、プラグインの最終出力を表示します。FFTではなく定Qフィルタバンク方式なので、低域が滑らかで高域の追従が速いのが特徴です
* バンドの中心周波数は VOCODER タブの **BANDS** 数に追従するので、画面と実際のフィルターが常に一致します

## 8. 音作りの出発点

| 狙う音 | 設定 |
|---|---|
| **王道ボコーダー** | Filterbank、BANDS 32〜48、TRACKING 0%、Sawキャリア、BASE PITCH を曲のキーに |
| **ロボット声 / BitSpeek** | LPC Mode、ORDER 8〜10、FRAME RATE 8〜15Hz、K QUANT 3〜4bit、INTERP Step |
| **ケロケロ** | TRACKING 100%、PITCH Q 100%、Key と Scale を指定 |
| **スケールを駆け上がる** | 上記に加えて MOD MATRIX で LFO → Master Pitch |
| **Color Bass** | FX1 = Resonator（Chord / Minor / DECAY 1.5秒 / SHIMMER 0.4 / INHARM 0.3）、FX2 = Drive |
| **EDMボーカルチョップ** | FX Gate、RATE 1/16、DECAY 35ms、VOWEL 0.6 |
| **ベル / 金属パッド** | Resonator を MIDI モード、DECAY 6〜10秒、INHARM 0.6、SHIMMER 0.5 |
| **トリッキー共鳴アルペジオ** | MOD MATRIX で LFO(S&H) → Resonator Shift、Resonator を MIDI モードに |

## 9. 150種類のファクトリープリセット

ヘッダーのプリセット名をクリックすると、8つのカテゴリーに分類された全150種類のファクトリープリセットを選択できます。★印でお気に入り登録も可能です。

1. **FilterBank (Auto)** — 20個: 自然なフォルマント、ポップス向けハーモニー、低音追従など
2. **LPC (Auto)** — 20個: 8-bitゲームロボット、知育玩具、スピーチIC、囁きなど
3. **FilterBank (MIDI)** — 20個: 鍵盤演奏可能な和音コード、リード、プラックなど
4. **LPC (MIDI)** — 20個: 演奏型トーキングベース、フォルマントシンセリードなど
5. **M.Pitch Modulations** — 10個: S&Hによる緩慢ピッチ変化、テンポ同期Arp、音階スナップなど
6. **Rhythmic Formant Gate** — 10個: 50パターンを活用したトランスゲート、32分スタッターなど
7. **Spectral Resonator Lab** — 10個: Shift変調、85%金属倍音、シマー拡散雲など
8. **SpecialFX** — 40個: 6スロット全Modと全FXを極限まで駆使した独創的サウンド（全MIDIモード、FilterBank/LPC各20個）

## 10. 困ったときは

| 症状 | 原因 |
|---|---|
| Autoモードで音が出ない | 入力ゲートが閉じています。トラックに音が来ているか確認してください |
| ボコーダーがこもる | CHARACTER を上げるか、明るいキャリア（Saw＋DETUNE少々）を使ってください |
| 言葉が聞き取れない | BANDS を増やす、CHARACTER を上げる、LPCなら ORDER を16に |
| ORDER を変えると音量が変わる | 仕様です。次数が低いほどキャリアが素通りするので、OUT LEVEL で調整してください |
| 共鳴が鳴り止まない | **DECAY** を下げてください。余韻の長さを直接決めるノブです |
| ゲートがリズミカルに聞こえない | **DECAY** を短く（30ms前後）するか、他のパターンを選んでください |
